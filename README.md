# BABO IS YOU · 바보이즈유

[Play BABO IS YOU](https://jonathanblackdoctor.github.io/babo-is-you/)

A puzzle about moving words, rewriting rules and crossing between two worlds. Includes 113 campaign puzzles and 20 grammar lessons.

Inspired by [Baba Is You](https://www.hempuli.com/Baba/). No assets, audio or levels from Baba Is You are bundled.

This repository contains only the playable website artifact.
